> [!IMPORTANT]
> Because of the growing complexity of ESLint configurations and the integration with other tools, it became too hard for us to maintain this package separately. The functionality has been moved to the official [`create-vue`](https://github.com/vuejs/create-vue) package and ESLint will be configured alongside other tools when creating a new Vue project.

# `@vue/create-eslint-config`

Utility to setup ESLint in Vue.js projects.

## Usage

Run the following command in your project root:

With npm:

```sh
npm create @vue/eslint-config@latest
```

With pnpm:

```sh
pnpm create @vue/eslint-config
```

With Yarn:

```sh
yarn create @vue/eslint-config
```
